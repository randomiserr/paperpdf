What’s editable

Text & typography
Rewrite paragraphs. Change fonts, size, color, and emphasis. Move or resize the text box.
Images & artwork
Add, move, and resize images. Recolor and arrange supported vector shapes and grouped artwork.
Page appearance
Change solid backgrounds, text color, and fonts on one page or across the document.
Highlights & notes
Mark an area or leave a comment. Undo and redo edits before saving your copy.

Text wraps within its paragraph; surrounding content stays in place. Scanned pages accept new text and images, but their existing text isn’t selectable.

Agent friendly

A documented codebase for coding agents, with callable PDF editing operations and a local HTTP API.

  • AGENTS.mdSetup commands, editing rules, and verification requirements.
  • docs/architecture.mdThe module map and the path from an edit to a PDF.
  • python verify.pyOne command for syntax, dependency, PDF, and interface regressions.

Edit requests include a document revision. Stale requests are rejected before they change the PDF.

Run it locally

Install Python 3.11 or newer, then open the project folder.

On Windows

Double-click start.bat. It creates the environment and installs dependencies on the first run.

Or use the terminal
python -m pip install -r requirements.txt
python server.py

Open 127.0.0.1:8765 in your browser and keep the terminal open.

Save before stopping the server. Documents and undo history are kept in memory.
